# История изменений

## [2.0.0] - 2026-10-13

### Добавлено
- Поддержка нескольких целей накоплений.
- Редактирование сумм и отметок по отдельным дням накоплений.
- Сводка накоплений и динамические рекомендации.
- Архивирование и восстановление целей накоплений.
- Расширенные API-тесты для валидации, граничных значений и изоляции данных пользователей.
- Автоматические проверки и деплой через GitHub Actions.

### Исправлено
- Улучшена работа календаря накоплений и расчёт сводных показателей.
- Усилена проверка доступа к данным целей накоплений.

### Проверки
- 21 API-тест успешно пройден в ручном запуске.
- Проверены основные страницы и health endpoint.
- PDF-отчёт проверен в браузере: содержимое и кириллица отображаются корректно.
- GitHub Actions: тесты и деплой успешно завершились.
