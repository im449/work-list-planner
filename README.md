# Work List Planner

Веб-приложение для управления задачами и личными финансовыми целями.
Проект развивается на Python и FastAPI и используется для практического
изучения разработки программного обеспечения.

**Демо:** https://work-list.ru

## Технологии

- **Backend:** Python, FastAPI
- **База данных:** SQLite
- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Отчёты:** генерация PDF
- **Развёртывание:** VPS, systemd, скрипт деплоя

## Возможности

### Управление задачами

- Канбан-интерфейс для организации задач
- Создание и редактирование задач
- Изменение статуса и архивация задач
- Административная панель с авторизацией
- Формирование PDF-отчётов

### Аккаунт и безопасность

- Смена пароля авторизованным пользователем через личный интерфейс
- Проверка текущего пароля перед изменением
- Минимальная длина нового пароля — 12 символов
- Инвалидация ранее выданных токенов после смены пароля
- Хранение паролей в виде хешей, а не открытого текста

### Накопления и финансовые цели

- Создание и ведение нескольких целей накоплений
- Настройка целевой суммы и срока накопления
- Календарь накоплений с редактированием сумм по дням
- Сводка по накоплениям и прогрессу достижения целей
- Архивация целей с сохранением их данных

### Годовой бюджет

- Планирование доходов и расходов по месяцам выбранного года
- Указание суммы, даты, категории и статуса операции
- Создание ежемесячно повторяющихся доходов и расходов
- Автоматическое создание отдельных операций на каждый месяц до конца года
- Корректная обработка дат 29, 30 и 31 числа с учётом длины месяца и високосных лет
- Независимое редактирование каждой созданной операции
- Разделение данных бюджета между пользователями

## Запуск для разработки

1. Клонируйте репозиторий и перейдите в каталог проекта.
2. Создайте виртуальное окружение:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Настройте необходимые переменные окружения, включая `SECRET_KEY`.
   Для локального запуска используйте отдельную тестовую базу данных, а не
   базу с данными рабочего приложения.

5. Запустите приложение:

   ```bash
   uvicorn main:app --host 127.0.0.1 --port 8000
   ```

## Тестирование

Запуск тестов из виртуального окружения:

    .venv/bin/pytest -q

Файл `conftest.py` настраивает отдельную временную базу SQLite для тестов.
Не запускайте автоматические тесты на базе данных рабочего приложения.
Предупреждения о deprecated-функциях не означают провал тестов, если все
тесты завершились успешно.

## Деплой

На настроенном сервере:

```bash
./deploy.sh
```

Скрипт обновляет код, перезапускает сервис приложения и выполняет проверки
доступности.

## Статус проекта

Work List Planner — развиваемый проект, развёрнутый на VPS.
Разработка включает расширение функциональности, улучшение пользовательского
интерфейса, поддержку финансовых целей и развитие серверного API.

Проект используется для практического освоения Python, FastAPI, работы
с базой данных, тестирования и развёртывания веб-приложений.
